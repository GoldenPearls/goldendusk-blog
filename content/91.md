# 뷰포트

### 실행하지 않은 환경에서 뷰포트 움직이기

1. `오른쪽 마우스`를 누른채
    1. q, w는 위 아래
    2. w, a, s, d 왼쪽 오른쪽 앞 뒤
2. 왼쪽 마우스도 가능하나 제한이 있다.
3. 만약 버벅거리면 세팅에서 수정이 가능

![](https://velog.velcdn.com/images/prettylee620/post/9f9463fe-1170-4f74-a392-eb447be85b7f/image.png)


4. 기본 레이아웃으로 돌아가기 window(창) > 레이아웃 불러오기 > 디폴트 에디터 레이아웃

![](https://velog.velcdn.com/images/prettylee620/post/8c4f619a-edca-4c03-b4db-363338023b6a/image.png)


5. 캐릭터의 시작 위치 : 깃발 영역

![](https://velog.velcdn.com/images/prettylee620/post/215d9efd-7339-462e-b2bf-05cedbcf5736/image.png)


6. 오른쪽 마우스를 누른채 마우스 휠 위 아래로 하면 카메라 속도 조정 가능

# 블루 프린트
## 블루프린트란?

- 시각 프로그래밍 언어로 텍스트 언어인 C++과 정반대
- 블루프린트는  언리얼 엔진에서 쓸 수 있으며, C++로 개발하려면 별도의 에디터가 필

## 블루프린트의 강정

1. 수정이 빠르다.
2. 초보자가 사용 가능
3. 내장 툴이 있어서 오른쪽 마우스로 기능을 찾아볼 수 있음
4. 언리얼 전용이라 콘셉트 충돌 같은 것이 없음
5. 디자이너/아티스트에게도 좋음

## C++의 강점

1. 블루프린트보다 훨씬 간결하다
2. 업계 표준 언어
3. 속도가 빠르다.
4. 언리얼의 모든 영역과 기능에 접근 가능
5. 대형 프로젝트에 적합

### 블루프린트와 C++는 함께 사용해야 한다.

> 블루프린트와 C++가 협업하는 시스템을 만들면 두 언어의 장점을 모두 누릴 수 있다.

- 언리얼 라이브러리는 대부분 C++로 작성됐지만 블루프린트로 가능한 것들은 웬만하면 다 접근이 가능하다.
- 직접 C++ 기능을 작성 시 블루프린트로도 사용 가능
