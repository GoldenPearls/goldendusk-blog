​

| 1. 친구랑 헤어지고 가는 길에 처음 들어가본 신촌역 과일가게예요 🚶 |
| --------------------------------------- |

신촌역 지나갈 때마다,

주황색 간판이 은근 눈에 띄었어요.(신촌역 2호선 라인 안에 있어요!)

​

푸릇해라는 이름도 그렇고,

과일 파는 곳인가 싶으면서도 막상 들어가 볼 일은 없었거든요.

​

이날은 친구랑 만나서 놀다가 헤어지고,

집 가는 길이었어요.


![](https://blogthumb.pstatic.net/MjAyNjA4MjhfMTgw/MDAxNzg3ODc1NzA0MzMy.50ROdBZnOiab72al3gPyJCi7BPy6c5ensITDEqP2fY0g.euFHkMuaandTV6z8NqQS2W-5mkM5oMLPXjD7wCTuS-og.JPEG/KakaoTalk_20260828_080507026.jpg?type=s3)


오다가다 볼 때마다 궁금했었는데,

오늘이야말로 한번 들러보자 싶어서 걸음을 옮겼어요 (˶ᵔ ᵕ ᵔ˶)

​

매장은 신촌역 안쪽 통로에 있어서,

지나가는 길에 자연스럽게 들르기 편했어요.

​

2026년 8월 기준으로 신규 오픈한 지 얼마 안 된 매장이라,

아직 다녀온 사람도 많지 않은 것 같더라고요.

| 2-1. 냉장고 가득한 과일들, 전체 메뉴 한눈에 봤어요 🗒️ |
| ----------------------------------- |

매장 밖는

큰 냉장고 두어 대에 과일이랑 컵과일이 가득 차 있었어요.


![](https://blogthumb.pstatic.net/MjAyNjA4MjhfNjMg/MDAxNzg3ODc1NzY2Njkw.nUdZFb6qOjgQYuZ_weDJ_7kg482mfI0ity3WWa9WJQwg.qaXLEB1Fv50qQxo44_eCCaEoSNwZjUgJUmV1NDOOnmsg.JPEG/KakaoTalk_20260828_080507026_01.jpg?type=s3)


즉석 생과일주스는 1잔에 **6,000원**,

생과일 캔주스는 1캔 **5,000원**, 3캔이면 **12,000원**이었고,

과일 요거트 산도는 1개 **8,000원**, 2개는 **15,000원**으로 적혀 있었어요.


![](https://blogthumb.pstatic.net/MjAyNjA4MjhfMjY0/MDAxNzg3ODc1NzkyNzk2.zxMSNmVhI5qi_Fkfmvgr8nbOXWAnYjCU2rPt0Hoimfog.cVQEXwHyS9NI4BxuzZ-CMrICqgXfUdKuMBPU959cf2Ug.JPEG/KakaoTalk_20260828_080507026_07.jpg?type=s3)


컵과일도 종류가 진짜 많았는데,

1cup은 **5,000원**, 3cup은 **12,000원**이었고,

수박·참외·포도·자두 같은 제철 과일들이 색깔별로 쭉 진열돼 있더라고요.

​


![](https://blogthumb.pstatic.net/MjAyNjA4MjhfMiAg/MDAxNzg3ODc1ODA3NDk2.SbPnjeVZG1wvBJDp1rUcxUkiNVKhpGdcin7jOUsW0eEg.1H8oGieMjZmJYhOz0zC-Q-30iuOuw0VxcvOjESe6bjMg.JPEG/KakaoTalk_20260828_080507026_06.jpg?type=s3)


매장 안쪽에는 통수박이랑 낱개 과일도 팔고 있었는데,


![](https://blogthumb.pstatic.net/MjAyNjA4MjhfMjQ0/MDAxNzg3ODc1ODExODk1.iDwc6OfXkY657y_bNQeC-GxyEl-2kAW93UJETA3d-Sgg.Az4FbYRy_OOVZtidrcDQt_q1cvpbVg19i3B6tQz-_l8g.JPEG/KakaoTalk_20260828_080507026_03.jpg?type=s3)


수박 5kg은 **10,000원**,

홍로사과는 1개 **6,000원**에 3개 **15,000원**,

골드키위는 6개 **10,000원** 이런 식으로 가격표가 붙어 있었어요.

​

이 부분은 제가 직접 먹어본 게 아니라 메뉴판이랑 가격표 보고 옮겨 적은 거라,

실제 맛은 다음에 사 먹어보고 나서 알려드릴게요 ( ˶°ㅁ°˶)

| 2-2. 이날은 수박주스 하나만 주문해봤어요 🍹 |
| --------------------------- |

메뉴가 워낙 많아서 뭘 먹을까 살짝 고민했는데,

날도 더웠고 수박이 딱 눈에 들어와서 수박주스로 정했어요.

​

주문하니까 사장님이 컵에 수박을 큼직하게 담아다가,

바로 갈아주셨어요.


![](https://blogthumb.pstatic.net/MjAyNjA4MjhfMjAw/MDAxNzg3ODc1OTA3NTg2.r2dZsHbdc3T9MtZvX1jLEQMoV_3i2qONjz3bbDH345Eg.9Ecm5J9BXXqSKrk8Sk4glppQIlckPN_kwmVD6AsGomog.JPEG/KakaoTalk_20260828_080507026_02.jpg?type=s3)


기다리는 시간도 그렇게 길지 않았고,

그 자리에서 바로 만들어주시는 걸 보니 즉석이라는 말이 맞더라고요.

제가 시킨 것 중 하나 수박주스 **6,000원**이었어요.

| 3. 첫입부터 왕 달고 시원했던 수박주스예요 🍉 |
| --------------------------- |

빨대 꽂고 한입 마셔봤는데,

수박이랑 얼음만 갈았다는데도 단맛이 진짜 확실하더라고요.

​

첫맛부터 달았고,

끝맛도 텁텁하지 않고 깔끔했어요.

​

얼음도 적당히 갈려 있어서 슬러시처럼 시원하게 넘어갔고,

더운 날 걸으면서 마시기 딱 좋았어요.

​

**수박이랑 얼음만 들어갔는데도 이 정도 단맛이 나오는 게 신기했어요.** (๑´ڡ&#x60;๑)

​

양도 생각보다 적지 않아서,

걸어가면서 다 마시고 나니 속이 시원해지는 느낌이었어요.

| 4. 컵과일이랑 캔주스는 다음에 도전해볼까 해요 🍇 |
| ----------------------------- |

이번엔 수박주스만 마셔봤지만,

**냉장고에 있던 컵과일들이 계속 눈에 밟히더라고요. ㅠㅠ**

​

수박주스처럼 마시고 가는 것도 좋지만,

집에서 편하게 먹으려면 컷팅 과일 사가는 것도 괜찮을 것 같았어요.

​

혼자 지나가면서 목만 축이고 싶다면 즉석주스,

집에 가서 나눠 먹고 싶다면 컵과일이나 캔주스 쪽이 더 맞을 것 같아요.

저는 다음에 갈 땐 컷팅 과일도 같이 사볼까 생각 중이에요 (｀・ω・´)

| 5. 신촌역에서 과일 살 곳 찾는다면 참고하기 좋아요 📍 |
| -------------------------------- |

신촌역 안쪽 통로에 있어서,

지하철 타고 다니다가 그냥 지나가는 길에 들르기 편했어요.


![](https://blogthumb.pstatic.net/MjAyNjA4MjhfNTcg/MDAxNzg3ODc1OTMzMzY5._wsaddgcl3UlvD008hBLNN2O_jaYucSYhRkAjjKC1oQg.qC6Bx2edwv0T_Rc7r6MqxzApM2-9gqnetmSmkt3-EFAg.JPEG/KakaoTalk_20260828_080507026_08.jpg?type=s3)


과일이나 즉석주스 살 곳을 따로 찾아다니지 않아도,

동선 안에서 자연스럽게 해결되는 느낌이었어요.

​

신규 오픈한 지 얼마 안 된 매장이라,

아직 정확한 영업시간까지는 확인을 못 했는데,

방문하실 분들은 가시기 전에 한 번 더 확인해보시는 게 좋을 것 같아요.

(대략 지나가면 본 느낌은 저녁 10시까지 하는 것 같았어요!)

직접 마셔보니 수박이랑 얼음만 갈았는데도 왕 달고 시원했던 수박주스였어요,

다음엔 컵과일도 사보고 싶어지는 곳이었어요 (˶ᵔ ᵕ ᵔ˶)
